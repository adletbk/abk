# Финансы

Личный трекер доходов и расходов для iPhone. Это PWA: ставится на экран «Домой» из Safari,
работает без сети, не требует Apple Developer аккаунта, подписок и сторонних сервисов.

Данные хранятся только у вас: на устройстве в IndexedDB и (начиная с вехи M3) в вашей
личной Google Таблице. В этом репозитории данных и токенов нет.

## Состояние

| Веха | Что входит | Статус |
|---|---|---|
| M1 | Каркас PWA, главная, добавление операции, офлайн | готово |
| M2 | Аналитика, категории, счета, шаблоны, бэкап JSON | готово |
| M3 | Google Apps Script, синхронизация, inbox | не начато |
| M4 | Разбор автоматических трат, Команды iOS | не начато |
| M5 | Импорт xlsx/csv из Money Manager | не начато |

## Запуск на компьютере

Нужен Node.js 22 или новее. Сборки нет: репозиторий и есть сайт.

```bash
npm install
```

```bash
npm run serve
```

Откройте http://localhost:4173. Тесты:

```bash
npm test
```

`npm install` ставит единственную dev-зависимость (`fake-indexeddb`) для тестов.
В само приложение она не попадает.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub и отправьте в него ветку `main`.
2. В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту приложение откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Установка на iPhone

1. Откройте адрес приложения в Safari.
2. Нажмите «Поделиться» → «На экран „Домой“» → «Добавить».
3. Запускайте приложение с иконки на экране «Домой».

**Важно.** У установленного приложения своё хранилище, отдельное от Safari. Операции,
введённые во вкладке Safari, в установленном приложении не появятся, и наоборот.
Пользуйтесь только иконкой на экране «Домой». Если удалить иконку, iOS удалит и данные
приложения. Поэтому делайте бэкап (см. ниже).

## Бэкап и экспорт

Настройки → «Экспорт и бэкап».

- **Сохранить бэкап.** Один JSON-файл со всеми операциями, счетами, категориями,
  шаблонами, начальными остатками и настройками. На iPhone откроется меню «Поделиться»:
  выберите «Сохранить в Файлы» (например, в iCloud Drive). Начиная с M3 в файле будет
  и токен синхронизации, поэтому не выкладывайте бэкап в общий доступ.
- **Восстановить из файла.** Заменяет все данные на устройстве содержимым бэкапа.
  Чужой, повреждённый или созданный более новой версией файл отклоняется, текущие
  данные при этом не меняются.
- **Операции в csv.** Таблица за выбранный период для Excel и Numbers: UTF-8 с BOM,
  разделитель запятая. Удалённые операции в файл не попадают.

Перенос на новый телефон: сохраните бэкап на старом, установите приложение на новом
и восстановите данные из файла.

При первом запуске приложение создаёт тестовые операции, чтобы экраны не были пустыми.
Их убирает кнопка «Удалить» в плашке «Это тестовые данные» на главной.

## Обновление

Приложение кешируется на устройстве. Чтобы установленная копия увидела новую версию:

1. После любого изменения файлов приложения выполните `node scripts/update-sw.mjs`.
   Скрипт увеличивает `VERSION` в [sw.js](sw.js) и пересобирает список кешируемых
   файлов `SHELL`; `npm test` проверяет, что список совпадает с файлами.
2. Отправьте изменения на GitHub.
3. Откройте приложение при наличии сети. Появится сообщение «Доступно обновление»,
   нажмите «Обновить».

Данные при обновлении не затрагиваются: они лежат в IndexedDB, а не в кеше файлов.
Схема базы меняется только добавлением миграции в конец списка `MIGRATIONS`
в [js/db.js](js/db.js); существующие миграции не редактируются.

## Безопасность

- Нет сторонних скриптов, CDN, аналитики и внешних шрифтов.
- Content-Security-Policy в [index.html](index.html): всё только со своего адреса,
  сетевые запросы разрешены только к `script.google.com` и `script.googleusercontent.com`.
- Удаление операций мягкое: запись помечается удалённой и остаётся в базе.

## Шрифт

[IBM Plex Sans](https://github.com/IBM/plex), © IBM Corp., лицензия SIL Open Font License 1.1.
Текст лицензии: [fonts/OFL.txt](fonts/OFL.txt). Файлы WOFF2 лежат в `fonts/`
(подмножества latin и cyrillic, плюс знаки валют). Знак тенге ₸ (U+20B8) есть в самом Plex,
запасной шрифт для него не нужен.

```
scripts/                                  dev-сервер, генерация иконок и fonts.css
tests/                                    тесты (node --test)
docs/superpowers/                         дизайн и планы вех
```
