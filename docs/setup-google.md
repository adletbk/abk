# Google Таблица и Apps Script

Таблица — облачная копия ваших данных и почтовый ящик для Команд iOS. Она лежит в вашем
Google Диске, скрипт работает от вашего имени. Сторонних сервисов нет.

Понадобится 10–15 минут и компьютер (в мобильном браузере редактор Apps Script неудобен).

## 1. Создайте таблицу

1. Откройте [sheets.new](https://sheets.new) под своим аккаунтом Google.
2. Назовите таблицу, например «Финансы».
3. Доступ не меняйте: таблица остаётся личной («Доступ ограничен»).

Язык и регион таблицы оставьте как есть. Лист «Лист1» можно не трогать.

## 2. Вставьте скрипт

1. В таблице: **Расширения → Apps Script**. Откроется редактор.
2. Удалите всё содержимое файла `Код.gs` (или `Code.gs`).
3. Вставьте целиком содержимое файла [apps-script/Code.gs](../apps-script/Code.gs) из этого репозитория.
4. Нажмите «Сохранить» (значок дискеты).

## 3. Создайте листы и токен

1. В редакторе выберите в списке функций `setup` и нажмите **«Выполнить»**.
2. Google попросит разрешения: «Проверить разрешения» → выберите свой аккаунт →
   «Дополнительные настройки» → «Перейти на страницу … (небезопасно)» → «Разрешить».
   Предупреждение появляется, потому что скрипт написан вами и не проходил проверку Google.
   Скрипт получает доступ только к этой таблице.
3. Внизу откроется **журнал выполнения**. В нём будет строка из 64 символов: это **токен**.
   Скопируйте его. Токен хранится в свойствах скрипта (Настройки проекта → Свойства скрипта,
   ключ `TOKEN`); в коде и в репозитории его нет.

В таблице появятся листы `transactions`, `categories`, `accounts`, `templates`, `inbox`
и «Сводка по месяцам».

Забыли токен: выполните `setup` ещё раз, он напечатает действующий токен, не меняя его.
Токен попал к посторонним: выполните `resetToken`, затем вставьте новый токен в приложение
и в Команды iOS.

## 4. Проверьте защиту от формул

Выберите функцию `selfTest` и нажмите «Выполнить». В журнале должно появиться:

```
OK: заметка «=1+1» сохранилась текстом, формулой не стала.
```

Это проверка на настоящей таблице: в автотестах проекта таблица поддельная. Если в журнале
«ОШИБКА», не включайте синхронизацию и сообщите об этом.

## 5. Разверните веб-приложение

1. В редакторе: **Развернуть → Новое развертывание**.
2. Значок шестерёнки → тип **«Веб-приложение»**.
3. «Запуск от имени»: **«От моего имени»**.
4. «У кого есть доступ»: **«Все»**.
5. «Развернуть». Скопируйте **URL веб-приложения**. Он выглядит так:
   `https://script.google.com/macros/s/AKfy…/exec`.

Доступ «Все» нужен, чтобы приложение и Команды iOS могли обращаться к скрипту без входа
в Google. Данные при этом защищает токен: запрос без верного токена получает отказ и
ничего не читает и не пишет. Адрес и токен никому не передавайте.

## 6. Подключите приложение

В приложении: **Настройки → Синхронизация**. Вставьте адрес и токен, нажмите «Подключить».
Приложение проверит связь и выполнит первую синхронизацию.

Дальше синхронизация идёт сама: при открытии приложения, через несколько секунд после
изменений и по кнопке со стрелками на главной. Без сети всё сохраняется на устройстве
и уходит в таблицу позже.

## Обновление скрипта

Когда `apps-script/Code.gs` в репозитории меняется:

1. Вставьте новый код в редактор и сохраните.
2. **Развернуть → Управление развертываниями → карандаш → Версия: «Новая версия» → Развернуть**.

Адрес при этом не меняется. Если создать «Новое развертывание», адрес изменится и его
придётся заново вставить в приложение и в Команды.

## Что лежит в таблице

Лист `transactions`: одна строка — одна операция.

| Колонка | Содержимое |
|---|---|
| Дата | `ГГГГ-ММ-ДД` |
| Время | `ЧЧ:ММ:СС` |
| Месяц | `ГГГГ-ММ` |
| Сумма | число без пробелов и знаков валюты, всегда положительное |
| Валюта | `KZT`, `USD`, … |
| Тип | `Расход`, `Доход` или `Перевод` |
| Категория, Счёт, Счёт зачисления | названия, а не id |
| Заметка | текст |
| Источник | `Вручную`, `Apple Pay`, `Уведомление банка`, `Импорт выписки`, `SMS` |
| Статус | `ок` или `проверить` |
| Удалена | `да` или `нет` |
| `id` … `key` | служебные колонки справа, их не редактируйте |

Для анализа берите строки, где «Удалена» = `нет`. Расход и доход различаются колонкой «Тип»,
знак у суммы всегда плюс. Переводы между своими счетами не доход и не расход.

«Сводка по месяцам» считается формулами и пересчитывается сама: доход, расход и баланс по
месяцам и расходы по категориям. Сводка считает только тенге.

В таблицу **не попадают**: начальные остатки счетов (они только на устройстве и в JSON-бэкапе)
и тестовые операции первого запуска.

Не переименовывайте листы и колонки и не меняйте их порядок: на них опираются формулы и
приложение. Если лист с таким именем уже существует с другими заголовками, скрипт откажется
писать (`schema_mismatch`) и ничего не тронет.

Строки вручную лучше не править: устройство считает свою версию главной и при следующей
правке операции перезапишет строку. Удалять строки тоже не нужно: удаление в приложении
мягкое, строка получает «Удалена» = `да`.

## Протокол

Один адрес, метод `POST`, тело — JSON. Приложение шлёт `Content-Type: text/plain`, чтобы
браузер не делал предварительный запрос; Команды iOS могут слать `application/json`.

```json
{ "token": "…", "action": "ping" }
```

| action | Назначение | Поля запроса |
|---|---|---|
| `ping` | проверка связи и токена | — |
| `add` | сырая запись в `inbox` (Команды iOS) | `text`, `source` (`applepay`, `notification`, `sms`), необязательные `time`, `id`, `payload` |
| `upsert` | создать или обновить записи пачкой | `transactions`, `categories`, `accounts`, `templates`, `inbox` (до 500 записей в каждом) |
| `pull` | изменения после метки времени и новые записи `inbox` | `since` (миллисекунды, из `server_time` прошлого ответа) |
| `delete` | мягкое удаление | `store`, `ids`, необязательное `deleted_at` |

Ответ всегда JSON с полем `ok`. Ошибка: `{ "ok": false, "error": "<код>", "message": "…" }`.

| Код | Значение |
|---|---|
| `unauthorized` | неверный токен |
| `not_configured` | токен не создан, выполните `setup()` |
| `bad_request` | тело не JSON или поля некорректны |
| `unknown_action` | неизвестное действие |
| `schema_mismatch` | лист с таким именем имеет другие заголовки или таблица новее скрипта |
| `busy` | таблица занята другой записью, повторите позже |
| `internal` | непредвиденная ошибка скрипта |

Гарантии, покрытые тестами (`tests/apps-script.test.js`, `tests/sync.test.js`):

- запрос без верного токена отклоняется для любого действия и не трогает таблицу;
- повторная отправка того же `id` не создаёт дубль; более старая версия записи не затирает новую;
- операция с уже существующим `fingerprint` не создаётся;
- запись в `inbox` с тем же `id` или с тем же текстом и временем события не дублируется;
- значения, начинающиеся с `=`, `+`, `-`, `@`, пишутся с ведущим апострофом;
- запись идёт под `LockService`;
- удаление мягкое.

Проверить связь с компьютера (подставьте свои адрес и токен, в историю команд токен
лучше не сохранять):

```bash
curl -L -H "Content-Type: text/plain" -d '{"token":"ВАШ_ТОКЕН","action":"ping"}' "ВАШ_АДРЕС"
```

Ожидаемый ответ: `{"ok":true,"server_time":…,"schema":1}`.

## Если не работает

| Что видно | Что сделать |
|---|---|
| «Сервер ответил не так, как ожидалось» | Адрес не от веб-приложения или доступ не «Все». Проверьте шаг 5; адрес должен заканчиваться на `/exec`. |
| «Неверный токен» | Скопируйте токен заново: `setup` в редакторе печатает действующий. |
| «В Apps Script не задан токен» | Выполните `setup`. |
| «Нет связи с веб-приложением» | Нет сети, либо адрес не существует, либо доступ не «Все»: браузер эти случаи не различает. Данные сохранены на устройстве и уйдут позже. |
| `schema_mismatch` | В таблице есть ваш собственный лист с именем `transactions`, `inbox` и т. п. Переименуйте его. |
